## 📖 О проекте

**QCC** — это компилятор для моего собственного языка программирования **Qora**. 

**Главная цель:** Создать легковесный и понятный компилятор, который транслирует код на Qora в байт-код для виртуальной машины **QezVM**. 

Проект пишется с нуля на C, чтобы полностью контролировать каждый этап компиляции — от чтения символов до генерации байт-кода.

## 🏗 Архитектура компилятора

Проект разбит на логические модули (классическая схема компилятора):
- 📂 `src/lexer` — Лексический анализатор (токенизация).
- 📂 `src/parser` — Синтаксический анализатор.
- 📂 `src/ast` — Абстрактное синтаксическое дерево (AST).
- 📂 `src/codegen` — Генератор кода.
- 📂 `src/bytecode` — Работа с байт-кодом для QezVM.
- 📂 `src/common` — Общие структуры и утилиты.

## 🚀 Как собрать

Для сборки используется `make`. Убедись, что у тебя установлен компилятор C (GCC или Clang).

1. Клонируй репозиторий:
   `git clone https://github.com/QeZzhi/QCC.git`
2. Перейди в папку проекта:
   `cd QCC`
3. Собери проект:
   `make`
4. Запусти компилятор (пример):
   `./qcc examples/hello.qora`
